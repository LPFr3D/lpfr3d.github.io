Sobre o Aplicativo

Verdade Desafio 18+ é um jogo de cartas para adultos destinado exclusivamente a maiores de 18 anos. O aplicativo funciona majoritariamente de forma offline — as cartas e mecânicas de jogo estão armazenadas localmente no dispositivo e não requerem conexão com a internet para funcionamento principal.

A conexão com a internet é utilizada apenas para:

  • Exibição de anúncios (usuários não-premium), via Google AdMob
  • Processamento de compras in-app (pacote premium), via Google Play Billing
3

Dados Coletados

3.1 Dados que NÃO coletamos

O desenvolvedor não coleta, armazena, transmite nem acessa diretamente nenhum dado pessoal dos usuários. Especificamente, este aplicativo não coleta:

  • Nome, e-mail, CPF ou qualquer identificador pessoal
  • Localização geográfica
  • Contatos do dispositivo
  • Fotos, vídeos ou arquivos
  • Histórico de navegação
  • Dados de saúde ou biometria
  • Conteúdo de mensagens ou chamadas
Armazenamento local Os nomes de jogadores digitados na tela de configuração da partida são armazenados apenas localmente no dispositivo (via SharedPreferences). Esses dados nunca saem do dispositivo e podem ser apagados a qualquer momento pela função "Limpar lista" dentro do próprio app ou em Configurações → Aplicativos → Limpar dados.

3.2 Dados coletados por terceiros

Os seguintes serviços de terceiros integrados ao aplicativo podem coletar informações para as finalidades descritas:

Google AdMob — anúncios (somente usuários não-premium)

O Google AdMob pode coletar e processar dados para exibição de anúncios, incluindo:

  • Identificador de publicidade do dispositivo (Advertising ID)
  • Dados de uso e interação com anúncios
  • Endereço IP (para geolocalização aproximada)
  • Informações do dispositivo (modelo, sistema operacional, idioma)

Usuários que adquirem o pacote premium não visualizam anúncios e não estão sujeitos a essa coleta pelo AdMob durante o uso do aplicativo.

Política de Privacidade do Google →    Configurações de anúncios →

Google Play Billing — compras in-app

Ao adquirir o pacote premium, a transação é processada integralmente pela Google Play Store. O desenvolvedor não tem acesso a dados de cartão de crédito ou informações financeiras. O aplicativo recebe apenas a confirmação de que a compra foi concluída com sucesso, para liberar o acesso premium.

Finalidade do Tratamento

Exibição de anúncios personalizados (AdMob) Legítimo interesse / Consentimento via configurações do SO
Mensuração de desempenho de anúncios (AdMob) Legítimo interesse

O aplicativo não utiliza os dados para tomada de decisões automatizadas com efeitos jurídicos ou significativos sobre o usuário.

Compartilhamento de Dados

O desenvolvedor não vende, aluga, comercializa nem compartilha dados pessoais com terceiros além dos serviços descritos na Seção 3.2, que são necessários para o funcionamento dos recursos de anúncios e compras.

Nenhum dado é compartilhado com:

  • Empresas de marketing ou listas de e-mail
  • Corretores de dados (data brokers)
  • Redes sociais
  • Quaisquer outras entidades não mencionadas nesta Política
6

Retenção de Dados

  • Nomes de jogadores (armazenamento local): retidos no dispositivo até que o usuário os exclua manualmente ou desinstale o aplicativo. Não há retenção em servidores externos.
  • Dados do AdMob: retidos conforme a política de retenção do Google, geralmente por até 18 meses para dados de anúncios.
  • Dados de compra (Google Play): retidos conforme os termos do Google Play e a legislação aplicável para fins fiscais e contábeis.
7

Segurança

Adotamos as seguintes medidas para proteger os dados tratados localmente:

  • Os dados armazenados localmente ficam no armazenamento privado do aplicativo, inacessível a outros apps sem root
  • Não realizamos transmissão de dados pessoais do usuário para servidores próprios
  • A compra premium é processada inteiramente pelo ambiente seguro do Google Play, com criptografia de ponta
Aviso Nenhum sistema é 100% seguro. Em caso de incidente de segurança que afete dados pessoais, notificaremos os usuários e a Autoridade Nacional de Proteção de Dados (ANPD) nos prazos previstos pela LGPD.
8

Direitos do Usuário

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD), você tem os seguintes direitos:

  • Acesso: saber quais dados seus são tratados
  • Correção: solicitar a correção de dados incompletos ou desatualizados
  • Eliminação: solicitar a exclusão dos dados tratados — para dados locais, basta usar "Limpar lista" no app ou desinstalar o aplicativo
  • Portabilidade: receber seus dados em formato estruturado
  • Oposição: opor-se ao tratamento realizado com base em legítimo interesse
  • Revogação do consentimento: retirar o consentimento para personalização de anúncios em Configurações → Privacidade → Anúncios
  • Informação: ser informado sobre os controladores com quem compartilhamos dados
  • Petição: peticionar à ANPD em caso de descumprimento da legislação

Como limpar os dados locais do app

  1. No Android, acesse Configurações → Aplicativos → Verdade Desafio 18+
  2. Toque em Armazenamento → Limpar dados
  3. Ou, dentro do próprio app, na tela de jogadores, toque em "Limpar lista"
