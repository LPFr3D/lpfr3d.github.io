Política de Privacidade

Farol Investidor — Controle seu patrimônio

Última atualização: outubro de 2025

Este documento descreve como o aplicativo Farol Investidor coleta, usa e protege as informações dos usuários. Ao criar uma conta e usar o app, você concorda com os termos aqui descritos.

1. Sobre o aplicativo

O Farol Investidor é um aplicativo gratuito de controle financeiro pessoal voltado ao acompanhamento do caixa mensal e da evolução patrimonial de pessoa física no Brasil.

2. Dados coletados

Para fornecer as funcionalidades do app, coletamos:

  • Dados de conta: nome e endereço de e-mail (cadastro por e-mail/senha ou login com Google).
  • Dados financeiros inseridos por você: movimentações de caixa, categorias, ativos, operações de compra/venda e dividendos.
  • Dados gerados pelo app: snapshots mensais do patrimônio total, usados para o gráfico de evolução.

Não coletamos dados de localização, contatos, câmera, microfone ou qualquer outro dado sensível além dos listados acima.

3. Finalidade do uso dos dados

Seus dados são utilizados exclusivamente para:

  • Fornecer e personalizar as funcionalidades do app;
  • Sincronizar seus dados entre dispositivos;
  • Gerar relatórios, gráficos e resumos financeiros para você.

Não vendemos, alugamos nem compartilhamos seus dados financeiros com terceiros para fins comerciais.

4. Armazenamento e segurança

Seus dados são armazenados no Google Cloud Firestore, banco de dados seguro com criptografia em trânsito (TLS/HTTPS) e em repouso. A autenticação é gerenciada pelo Firebase Authentication. Adotamos as melhores práticas de segurança recomendadas pelo Google Firebase.

5. Serviços de terceiros

O app utiliza os seguintes serviços do Google Firebase:

  • Firebase Authentication: gerenciamento de contas e login seguro.
  • Cloud Firestore: armazenamento dos dados financeiros.
  • Cloud Functions: atualização automática de cotações de ativos.

Esses serviços estão sujeitos à Política de Privacidade do Google .

6. Seus direitos (LGPD)

A Lei Geral de Proteção de Dados (Lei 13.709/2018) garante a você o direito de:

  • Acessar todos os dados que você inseriu no app;
  • Corrigir informações incompletas ou imprecisas;
  • Excluir sua conta e todos os dados associados;
  • Revogar o consentimento a qualquer momento.

Para exercer esses direitos, acesse Config → Excluir conta no app. A exclusão é imediata, permanente e irreversível.

7. Crianças

O Farol Investidor não é destinado a pessoas menores de 18 anos e não coleta intencionalmente dados de menores. Se tomarmos conhecimento de que coletamos dados de um menor, excluiremos essas informações imediatamente.

8. Alterações nesta política

Podemos atualizar esta política periodicamente. Caso as mudanças sejam significativas, notificaremos por meio do app ou por e-mail. A data de "Última atualização" sempre refletirá a versão vigente.
